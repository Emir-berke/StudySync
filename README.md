
# StudySync

StudySync is a collaborative study platform where students
can create or join study sessions and manage tasks together.

## Technology Stack
- React + Vite
- Node.js
- Express.js
- MongoDB + Mongoose

## Core Objects
- User: Student accounts
- Session: Collaborative study sessions
- Task: Tasks belonging to a study session

## Project Structure
- client/ - React frontend
- server/ - Express backend

## Getting Started

### Frontend
cd client
npm install
npm run dev

### Backend
cd server
npm install
node server.js

## API
GET /api/health

## Team Conventions
- Use feature branches for development.
- Do not push directly to main.
- Open pull requests for code reviews.
- Never commit .env files or passwords.
- Use clear commit messages.
